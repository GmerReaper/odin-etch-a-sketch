# Etch-a-Sketch

A browser-based Etch-a-Sketch drawing app built as part of The Odin Project foundations curriculum.

## How to Use

- Hold and drag your mouse to draw on the grid
- Use the sidebar buttons to switch between drawing modes
- Click "Create a New Grid" to set a custom grid size (up to 100x100)

## Modes

- **Color Mode** - draws random colors that darken over 10 interactions
- **Bright Mode** - draws bright colors or white depending on color mode
- **Black Mode** - always draws black
- **Erase Mode** - erases cells back to their original state
